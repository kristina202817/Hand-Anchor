# Hand Anchor

A calming interactive web experience: a glowing sphere responds to your hand movements, tracked in real time through your webcam.

Designed and prototyped in Figma Make.

## Tech
React · TypeScript · Vite · Tailwind CSS · MediaPipe Hand Tracking

## Run locally
```bash
pnpm install
pnpm dev
```
Allow camera access in the browser when asked.
